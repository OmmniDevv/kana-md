# PRICELIST Resmi Bot KANA

Daftar harga resmi Premium dan Sewa bot KANA. Harga ini yang tampil di web https://kana.omnicorp.web.id/premium dan menjadi acuan aktivasi manual oleh owner.

## Premium Personal (per nomor)

| Durasi | Harga |
| --- | --- |
| 7 hari | Rp3.000 |
| 30 hari | Rp8.000 |
| 90 hari | Rp20.000 |
| Permanen | Rp50.000 |

Keuntungan: semua fitur premium terbuka (AI chat dan AI gambar, vision, TTS, removebg, ssweb, OCR, game premium, jadibot termasuk), limit download naik dari 5 menjadi 50 kali per hari, limit upscale naik dari 3 menjadi 20 kali per hari.

## Sewa Grup (per grup)

| Durasi | Harga |
| --- | --- |
| 7 hari | Rp2.000 |
| 30 hari | Rp5.000 |
| 90 hari | Rp12.000 |
| Permanen | Rp30.000 |

Keuntungan: fitur premium terbuka untuk semua member di grup itu saja, limit grup naik sama seperti premium (download 50 kali per hari, upscale 20 kali per hari). Jadibot TIDAK termasuk sewa grup.

## Sewa Jadibot (per nomor)

| Durasi | Harga |
| --- | --- |
| 7 hari | Rp4.000 |
| 30 hari | Rp10.000 |
| 90 hari | Rp25.000 |
| Permanen | Rp65.000 |

Keuntungan: bisa menjalankan jadibot (nomor sendiri jadi bot) selama masa sewa, tanpa harus premium personal.

## Pembayaran dan Aktivasi

- Pembayaran memakai QRIS yang tampil di web https://kana.omnicorp.web.id/premium (semua e-wallet dan bank), berlaku untuk Premium, Sewa Grup, Sewa Jadibot, dan donasi.
- Sesudah membayar, pembeli mengirim bukti transfer ke owner via WhatsApp.
- Aktivasi manual oleh owner memakai perintah .addprem dan .addsewa. Tidak ada payment gateway.
