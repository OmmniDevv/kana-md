# DECISIONS

- 2026-11-04: Nama bot KANA (bukan Elaina), persona moe gaya Kana. Nama repo GitHub: kana-md, publik, lisensi MIT.
- 2026-11-04: Pairing ditunda. NOMOR_BOT dan NOMOR_OWNER belum diberikan user, jadi base memakai placeholder di .env.example dan `npm start` berhenti rapi dengan pesan bila BOT_NUMBER kosong.
- 2026-11-04: Folder ./reference/ tidak tersedia di workspace, tidak ada kode referensi yang dibaca atau disalin.
- 2026-11-04: Versi library di-pin exact 1.4.7 dari hasil `npm view`.
- 2026-11-04: `checkHtmlApp` di v1.4.7 adalah named export top-level, bukan properti MB. Kode mengimpornya dari root paket.
- 2026-11-04: `usePostgresAuthState({ pool, session: 'kana' })` dipakai untuk driver supabase sesuai README. Untuk driver local dipakai `useMultiFileAuthState` di .dev-data/session (dev saja).
- 2026-11-04: Kode pairing kustom 8 karakter: KANAMOE1.
- 2026-11-04: Base dirampingkan mengikuti prinsip minimum yang jalan: tanpa Dockerfile, scheduler, dan scraper dulu. Itu pekerjaan fase berikutnya setelah Gate 1.
- 2026-11-04: Aset gambar dikomposisi lokal dengan PIL dari maskot resmi Kana (pose halo dan fight), bukan gambar dari web atau referensi.
- 2026-11-04: Scraper kiriman user dipasang sebagai Fase downloader/search lebih awal atas perintah langsung user di chat utama (mengalahkan urutan Gate 1 untuk cakupan ini saja; pairing tetap menunggu nomor). Enam scraper user (Spotify, YouTube, Pinterest, Facebook, Instagram, TikTok) jadi modul di src/scrapers dengan runner bersama (SSRF guard, retry, circuit breaker).
- 2026-11-04: YouTube downloader tidak lagi menulis folder downloads permanen; audio lewat folder temp yang selalu dihapus, dikembalikan sebagai Buffer.
- 2026-11-04: TikTok memakai dua sumber: tiklydown (utama, dari user) dan tikwm (fallback, adaptasi snippet Jerexd di dpaste). Hasil dinormalisasi ke satu bentuk.
- 2026-11-04: Dua snippet paste diadaptasi (Komikcast dan DaFont, kredit Jerexd di header file dan docs/SNIPPETS.md). Sisanya dilewati dengan alasan tercatat di docs/SNIPPETS.md, termasuk tool aktivasi premium (dilarang aturan proyek) dan link yang tidak bisa diakses.
- 2026-11-04: Metadata dan lirik memakai modul Yui Agents (Spotify Embed, iTunes, lyrics.ovh, lrclib) sebagai plugin .lirik dan fallback metadata plugin .spotify.
- 2026-11-04: AI chat rudder.chat bersifat opt-in penuh: kredensial hanya dari .env (RUDDER_USER_ID, RUDDER_COOKIE_C0, RUDDER_COOKIE_C1, RUDDER_TH_WHO), tidak ada nilai hardcoded; tanpa env, plugin .ai membalas belum dikonfigurasi.
- 2026-11-04: Auto bio: template lewat .env (BIO_ON_TEMPLATE dan BIO_OFF_TEMPLATE, placeholder {bot}, {runtime}, {since}) sesuai keputusan mekanisme yang diserahkan user; default moe bawaan kode bila env kosong. Interval pembaruan 5 menit: updateProfileStatus adalah IQ profil yang murah, tetapi WhatsApp sensitif rate limit untuk perubahan profil, jadi 5 menit dipilih sebagai titik aman antara bio yang terasa hidup dan risiko pembatasan; runtime per menit tidak cukup penting untuk dibayar dengan risiko itu. Toggle AUTO_BIO default true.
- 2026-11-04: Pemuatan .env memakai process.loadEnvFile() bawaan Node lewat src/load-env.js yang diimpor pertama di src/index.js, bukan flag --env-file di script start, supaya node src/index.js langsung juga benar dan tidak bergantung pada cara menjalankan. File .env tidak ada ditoleransi (try/catch).
- 2026-11-04: Jeda requestPairingCode 6000 ms (dari 3000 ms) berdasarkan bukti live: 3 detik gagal Connection Closed dan sisa sesi korupnya memicu loggedOut di run berikutnya; 6 detik berhasil dengan kode KANAMOE1. Pembersihan sesi korup tetap lewat clearAuth() pada jalur loggedOut, mekanisme yang disediakan library.
- 2026-11-04: Aturan tetap dari user: SEMUA fitur wajib memakai button. Setiap keluaran dengan langkah lanjutan menyertakan tombol MB.Button via src/ui/buttons.js; id tombol adalah perintah valid yang tertangkap pipeline; fallback teks selalu ada.
- 2026-11-04: Sistem DAFTAR WAJIB dari user: user harus terdaftar (field registered/regName/registeredAt) sebelum memakai bot. Gate ditegakkan di pipeline: yang belum terdaftar hanya boleh .daftar dan .help daftar, .menu menampilkan peringatan daftar, owner selalu lolos. Statistik web hanya menghitung user terdaftar sebagai member.
- 2026-11-04: .daftar berkategori main (keputusan user), walau filenya tetap di plugins/user/ agar riwayat dan tes Fase 2 tidak berpindah.
- 2026-11-04: Persona dibuat ekspresif atas perintah user: pool moe diperkaya emoji dan kaomoji variatif; batas lama prompt (maks 1 kaomoji + 3 emoji per pesan) dinyatakan dilonggarkan oleh user sendiri. Informasi inti tetap tidak boleh tertutup dekorasi.
- 2026-11-04: Perluasan fitur di luar katalog minimum diizinkan user (tools kecil, fun, ekonomi) selama mematuhi daftar larangan §1 prompt dan standar tes yang sama.
- 2026-11-04: Server skor game adalah WebSocket murni Node (node:http + node:crypto) tanpa dependensi baru; token skor HMAC-SHA256 per pemain (secret env GAME_TOKEN_SECRET, fallback hash nomor bot+owner); skor divalidasi (token, kedaluwarsa, batas per game, rate limit) sebelum disimpan sebagai skor terbaik di namespace scores.
- 2026-11-04: Hapus pesan oleh middleware grup memakai sock.sendMessage(chat, { delete: raw.key }); bentuk ini terverifikasi di source library v1.4.7 (messages-send.js), bukan contoh README.
- 2026-11-04: Alias 'game' pada plugin contoh .hello dilepas karena .game menjadi perintah katalog game yang asli; alias 'leaderboard' pada .topgame dilepas (diganti 'topskor') karena leaderboard XP adalah perintah tersendiri.
- 2026-11-04: Tes pipeline lama (pipeline-core, pipeline-buttons) disesuaikan terhadap gate daftar: user uji dianggap terdaftar agar tes gates lain tetap terisolasi.
- 2026-11-04: Pengingat pribadi disimpan di namespace 'reminders' (key digit user, array {at, text, chat}) dan dikirim scheduler pada tick menitannya; bahasa memakai preferensi user.
- 2026-11-04: Alur login web FINAL dari user: member memasukkan nomor di web lebih dulu; web menulis web_login_requests dan watcher bot yang mengirim kode verifikasi via WhatsApp (menghapus codePlain sesudah kirim). .webcode dipertahankan hanya sebagai cadangan manual.
- 2026-11-04: Record web_login_requests yang kedaluwarsa DIHAPUS watcher (bukan ditandai), karena kontrak status web hanya mengenal pending/sent/used; ketiadaan record berarti web harus meminta kode baru. Tombol salin (cta_copy) tidak dicampur dengan quick_reply sesuai aturan library; .webcode mengirim kode sebagai teks + tombol menu.
- 2026-11-04: .ai tidak lagi wajib rudder: provider dipilih otomatis (rudder bila terkonfigurasi, selain itu Pollinations teks publik gratis). Memori percakapan disimpan per user di kv aimem (maks 6 pasang) dan hanya dipakai untuk konteks .ai.
- 2026-11-04: Jadibot dibatasi keras: owner-only, maks 3 sesi, auth terpisah per nama sesi, pipeline dan registry yang sama. Sesi jadibot adalah bot penuh di nomor lain, jadi tidak ada jalur pengguna biasa untuk membuatnya.
- 2026-11-04: Alias antar-batch yang bentrok diselesaikan dengan melepas alias di plugin yang lebih khusus namanya: tekateki melepas alias 'tts' (jadi 'teka'), tebakgambar melepas 'gambar' (jadi 'tbgambar'), recipes RPG melepas 'resep'. Loader berakhir 0 karantina dengan 174 plugin.
- 2026-11-04: Slot, blackjack, daduvs, dan gacha memakai koin virtual profil (balance) saja; tidak ada uang asli, tidak ada pembayaran, sesuai daftar larangan proyek.
- 2026-11-04: Harness livetest tidak memvonis lulus/gagal otomatis (Mode A dinilai visual oleh owner di HP); kolom expect di file hasil adalah panduan pencocokan, dan harness berhenti total bila sinyal kesehatan akun menunjukkan pembatasan.
- 2026-11-04: Koreksi menu pada tahap ini kemudian digantikan oleh koreksi final user di bawah yang mewajibkan port dari SC Elaina-MD v6.3.0 milik owner sendiri. Status aktif menu mengikuti keputusan final tersebut, bukan teks penuh tanpa tombol dari tahap ini.
- 2026-11-04: Keputusan gambar menu pada tahap ini kemudian digantikan oleh koreksi final user di bawah: banner tidak lagi memakai mekanisme kartu iklan eksternal, dan helper fake quoted ditulis ulang mengikuti SC Elaina-MD v6.3.0 milik owner. Menu user belum daftar tidak berubah.
- 2026-11-04: Perbaikan harness livetest: TEST_CHATS berupa digit mentah dinormalisasi menjadi JID penuh "<digit>@s.whatsapp.net" (normalizeChatJid di scripts/livetest.js) sebelum pesan sintetis dibangun; sebelumnya remoteJid digit mentah membuat jidDecode gagal dan semua uji builtin error di level handler. Pengaman harness lain tidak berubah.
- 2026-11-04: KOREKSI FINAL user soal referensi menu: mekanisme menu wajib diport dari SC Elaina-MD v6.3.0 milik owner sendiri (repo OmmniDevv/Elaina-MD), bukan dari SC publik.
